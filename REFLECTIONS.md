# Reflections

1. Share one aspect of building this project you found challenging and how you
   overcame it.

```
I feel that for me, still the most difficult requirement for this project was the use of dictionaries. I am still grasping both iterating through a dictionary as well as pulling specific details from dictionaries. The prime example of this within my project is the creation of each product within the item dictionary. The way that I mainly overcame this challenge was referencing the gitbook as much as possible, as well as turning to Claude when it was absolutely necessary. I found that rereading notes, and then trying to write out the concept myself after reading was an effective method to really grasp the concept. I could then apply this to my own project. Now the user is able create items properly and remove them as they please by entering the name of the item. Additionally, if an item is entered more than once, the price isn’t asked for the second time, and the quantity is added together, with only one listing of that item.
```

2. Share one technical concept that you gained a deeper understanding of
   through building this project. Explain that concept in simple terms and
   explain how it is used in your project.

```
One technical concept that I feel I now have a deeper understanding of is the usage of try/except. The basic idea for this concept is preparing for errors that might exist within your code, and deciding what to do with them when they inevitably come up. This is both so that you are getting the intended output, but also so that your program doesn’t crash and end earlier than you intend it to. The way that this is being used in my project is to make sure that the user inputs are in the intended format so that they can be used properly. Specifically, this is used when asked for both the price and the quantity of the item being added. If we didn’t do this, we would raise an error if a user was to input a string. Additionally, if we didn’t specify needed an int and a float respectively, we wouldn’t be able to find the total for both at the end of the shopping list. 
```
